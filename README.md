# Programación para Analítica Descriptiva y Predictiva

Este repositorio contiene las **clases, prácticas y tareas** correspondientes a la materia **Programación para Analítica Descriptiva y Predictiva**.

El objetivo del curso es desarrollar las bases de programación necesarias para el **análisis de datos**, la **analítica descriptiva** y la **analítica predictiva**, utilizando principalmente **Python** y sus librerías orientadas a ciencia de datos.

---

## 📘 Clases
Las clases incluyen notebooks con explicaciones teóricas y ejemplos prácticos sobre los temas vistos en el curso, tales como:

- Fundamentos de Python
- Estructuras de datos
- NumPy
- Pandas
- Manipulación y análisis de datos
- Introducción a conceptos de analítica descriptiva y predictiva

Cada notebook de clase puede ejecutarse directamente en **Google Colab**.

---

## 🧪 Prácticas
Las prácticas están orientadas a **reforzar los conceptos vistos en clase** mediante ejercicios aplicados.
